# React frontend for Reps and Revenue

Template was built with create-react-app, run using NPM

## Installation

- Install
```bash
npm install --legacy-peer-deps
```
- Build

```bash
npm build
```

Build configs are set to go from a dist folder that is then served by the django backend. Running the frontend locally works, but causes some issues where pages expect results from the backend but end up returning an error.
